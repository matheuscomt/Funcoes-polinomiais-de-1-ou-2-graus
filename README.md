## 📌 Sobre o Projeto

**Missão Matemática** é um site educativo interativo desenvolvido como atividade avaliativa da unidade **"Algoritmos: criando uma aventura com HTML, CSS e JavaScript"**. O objetivo é construir **modelos empregando funções polinomiais de 1º e 2º graus** para resolver problemas em **contextos diversos**.

A proposta utiliza uma **narrativa de exploração espacial** onde o estudante assume o papel de um **Comandante** que precisa resolver 5 missões matemáticas para salvar a galáxia! 🌌

### 🎯 Objetivos de Aprendizagem

- ✅ Compreender funções do 1º grau (f(x) = ax + b)
- ✅ Compreender funções do 2º grau (f(x) = ax² + bx + c)
- ✅ Calcular raízes, vértice, delta e concavidade
- ✅ Aplicar funções em situações-problema reais
- ✅ Interpretar gráficos de funções polinomiais
- ✅ Resolver problemas de otimização

## ✨ Funcionalidades

### 🎮 Interatividade
- 🌟 **Campo estrelado animado** no fundo (gerado via JS)
- 📊 **Gráficos dinâmicos** desenhados em Canvas para cada função
- 🧮 **Simuladores interativos** com parâmetros ajustáveis em tempo real
- 🏆 **Quiz final** com 5 perguntas e feedback educativo
- 📱 **Totalmente responsivo** (mobile, tablet, desktop)
- 🎯 **Navegação suave** entre seções
- 🔝 **Botão "voltar ao topo"**
- 📈 **Contadores animados** na hero section

### 📚 Conteúdo Educacional
- 📖 Briefing teórico com fórmulas e conceitos
- 🎯 5 missões com contextos diferentes
- 🧠 Desafios propostos em cada missão
- 💡 Explicações detalhadas no quiz
- 📉 Visualização gráfica de cada função

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Uso | % do Projeto |
|------------|-----|--------------|
| **HTML5** | Estrutura semântica, formulários, canvas | 30% |
| **CSS3** | Design responsivo, animações, gradientes | 35% |

### 📦 Recursos Específicos
- **Canvas API** → Plotagem de gráficos de funções
- **Intersection Observer** → Animações ao scroll
- **localStorage** → (preparado para salvar progresso)
- **Google Fonts** → Orbitron e Exo 2
- **CSS Variables** → Tema espacial customizável
- **Flexbox & Grid** → Layout responsivo
